# PUMP – Personal Workout Manager

PUMP is a web app to help users manage personal workout plans, track progress, and get recommendations.  
The system is designed to be simple, accessible, and free for both beginners and advanced users.

## Goals
- Maintain a database of exercises with instructions and images  
- Create and manage personalized workout plans  
- Track progress and visualize improvements  
- Accessible from any device

## Architecture & Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript, Chart.js/Recharts, TailwindCSS/Material UI  
- **Backend:** Node.js + Express, MVC pattern, bcrypt, JWT, Helmet  
- **Database:** PostgreSQL with ORM (Prisma/Sequelize)  
- **Tools:** Git/GitHub, Azure DevOps Pipelines, Jest/Mocha, VS Code, Postman
